# TECHNOVA 2026 — Student Technology Event

A responsive single-page event website inspired by the visual style of modern university tech-event sites. Built with HTML, CSS, and vanilla JavaScript.

## Included
- Hero section and event details
- Live countdown to 15 October 2026 at 10:00 AM (visitor's local time)
- About section and activity cards
- Event schedule
- Illustrative gallery tiles (replace with real event photos when available)
- Registration form with browser-side validation
- Mobile navigation and responsive styling

## Files
- `index.html` — website content and structure
- `style.css` — styling and responsive layout
- `script.js` — countdown, mobile menu and form validation

## Preview locally
Open `index.html` in a modern browser. An internet connection is needed to load the optional Google Fonts; the site otherwise uses fallback fonts.

## Publish using GitHub Pages
1. Create a GitHub repository, e.g. `technova-2026`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After publishing, GitHub Pages will show your website URL in the Pages settings.

## Important before publishing
- Replace `technova@example.com` and `9876543210` with official event contact details.
- The registration form is currently a front-end demo: it does not send, store or email submitted details. Connect a backend or form service before using it for real registrations.
- Gallery tiles are CSS illustrations, not photographs from a real event.
